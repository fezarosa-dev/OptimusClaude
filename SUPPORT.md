# Suporte

## Onde pedir ajuda

1. Leia o [README](README.md) e a pasta [docs](docs/). A maioria das dúvidas está lá.
2. Procure uma [issue](https://github.com/fezarosa-dev/OptimusClaude/issues) existente, aberta ou fechada.
3. Não achou? Abra uma issue pelo formulário certo (bug ou ideia) e preencha os campos.
4. Se a aba **Discussions** estiver ligada no repositório, use-a para perguntas abertas e troca de experiência.

Para falha de segurança, não use issue: veja o [SECURITY.md](SECURITY.md).

## O que não é suporte deste projeto

- Problemas do próprio Claude Code (travamentos, limites de uso, conta, cobrança): abra issue nos canais da Anthropic.
- Ferramentas de terceiros que o kit usa: procure os projetos delas.

Este é um projeto mantido por uma pessoa, em tempo livre. Respostas podem demorar.
